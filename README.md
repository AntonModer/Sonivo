Sonivo is an unofficial Android music client based on MySpoti and Revera, designed to deliver a customizable music listening experience with a refreshed identity, neon branding, and advanced playback features.

✨ Features

- Spotify account integration
- Modern interface with neon branding
- AutoMix and smooth track transitions
- Adjustable crossfade
- Spotify Connect integration
- Lyrics support
- Interface customization
- Adjustable font size
- Extension support
- Background music playback
- Built-in changelog
- Diagnostic tools and application logs

📥 Download

Download the latest APK from the Releases section of this repository.

📲 Installation

1. Download "Sonivo-1.1.0.apk".
2. Allow installation from unknown sources if required.
3. Install and launch Sonivo.
4. Sign in with your Spotify account.
5. Customize your listening experience.
